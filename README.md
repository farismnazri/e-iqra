# Iqra (اقرأ)

**Iqra** is an early-stage, free, self-guided **Quranic Arabic reading workbook** for beginners, including adult reverts and learners studying independently.

The goal is simple: make it easier to start recognizing Arabic letters, reading their vowel marks, and practising at a comfortable pace. Iqra is a reading primer, **not** a general Arabic language course, a Quran companion app, or a substitute for a qualified recitation teacher.

## Intended experience

- **Start reading without an account.** Choose a chapter and open an exercise page in just a few actions.
- **Read, optionally listen, and self-check.** Reference audio is offered only when approved; progress is not dependent on audio.
- **Return where you left off.** Reading progress is chapter-specific, with optional accounts planned for syncing across devices.
- **Optional writing practice.** A simple trace-and-write activity complements reading; it is not graded.
- **Calm, accessible design.** The interface takes inspiration from a warm paper workbook rather than a dashboard or game.

## Project status

**Pre-implementation / design stage.** The application has not yet been scaffolded or released. The initial software scope is Chapter 1; later chapters are curriculum-planning work and are not automatically part of the first release. Lesson content and pronunciation references require qualified teacher review before publication.

The planned technical direction is a responsive React + TypeScript web application, subject to actual project setup and implementation decisions.
